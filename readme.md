# Regulatory Reporting Automation application

A Streamlit-based regulatory reporting simulation platform that:

- Accepts manual CSV uploads
- Performs inbound data validation
- Detects threshold breaches
- Generates monthly regulatory summaries
- Maintains audit logs
- Visualizes transaction trends

## Tech Stack
- Python
- Streamlit
- SQLite
- Pandas
- Matplotlib

## Features
- User-uploaded CSV ingestion
- Custom validation rule input
- Date-based filtering
- Monthly transaction aggregation
- Breach detection engine
- Audit trail logging

## Why This Project?
Built to simulate how financial institutions automate manual regulatory reporting workflows while maintaining data integrity and auditability.
